Privacy policy

Last updated: 13 October 2026

Shorts Hub is a personal tool operated by Maksim Sidelskij ("we") for uploading videos to channels we own. This policy explains what it does with data.

What data it uses

When the channel owner signs in with Google, Shorts Hub receives an access token for the YouTube Data API with permission to upload and manage videos and to read basic channel information (the channel name and video statistics such as views and likes).

How it is used

  • To upload videos, set titles, descriptions, tags and scheduled publishing times on the owner's own channels.
  • To read view and like counts of those videos so the owner can see how they perform.

Shorts Hub does not access, collect or store data about viewers or any other YouTube users, and it does not sell, share or transfer any data to third parties. It does not use the data for advertising.

Storage and security

Sign-in tokens are stored only on the owner's computer and as an encrypted secret in the owner's private GitHub repository, used solely to run the uploads. They can be deleted at any time.

Data retention and deletion

Shorts Hub does not keep copies of any YouTube API data beyond what is needed for the current task. View and like counts of the owner's own videos are refreshed regularly and are never stored for longer than 30 days without being refreshed or deleted. Sign-in tokens are deleted as soon as access is revoked. The owner can ask for any stored data to be deleted at any time by writing to the contact address below; it is deleted within 7 days.

Revoking access

Access can be revoked at any time from the Google Account security settings: myaccount.google.com/permissions.

YouTube API Services

Shorts Hub uses YouTube API Services. By using it you also agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.
